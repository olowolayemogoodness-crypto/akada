# Recording the voice for Edulink Shorts

Each short plays a recorded clip for every line. Record one file per line in a quiet room (a phone is fine), speak naturally in your normal Nigerian English, a little faster than a lesson, with energy, as if you are telling a friend something exciting.

Save each clip as MP3 in a folder named after the short, numbered from 1:

```
app/shorts/voice/chem-hcl-1/1.mp3
app/shorts/voice/chem-hcl-1/2.mp3
...
```

When every clip of a short is there, the app uses your voice and times the animation to it automatically. If any clip is missing, it falls back to the computer voice.

Tips: leave about half a second of silence at the start and end of each clip; say chemical formulas as words (the "Say" column); keep each clip under 6 seconds.
